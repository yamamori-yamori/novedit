# 左で参照して右で書く２ペインテキストエディタ　novedit

設定やプロット、推敲前の文章などを左側に表示してタブ切り替えで見ながら、右側で執筆できるテキストエディタです。

- 作者: [やまもりやもり](https://yamamori-yamori.github.io/mypage/)

- 外部サーバー・CDN不要。完全ローカルHTML。
- ブラウザでHTMLファイルを開くだけで動作します。Windows / mac / iPadなどプラットフォームを問いません(chrome推奨)
- 日本語長編小説を前提に設計されています。10万文字超えていても快適に動作します。
- ミニマップ上でも全体検索でハイライト表示など、一覧性の良さに特化しています。

---

## 使い方

1. [こちら](https://github.com/yamamori-yamori/novedit/raw/refs/heads/main/novedit.zip)をダウンロードしてzipを解凍し、`novedit.html` をブラウザで開く（Chrome 推奨）。
   または、 [作者HP](https://yamamori-yamori.github.io/mypage/)から「WEB版」をご使用ください。

2. 右ペインクリックまたはドラッグで編集したいファイルを設定。左ペインには参照したいテキストファイルをまとめて設定できます。
4. 基本的にブラウザに自動保存されています。ブラウザを閉じても次回開いたときに続きを再開できます。
5. 左ペインで選択した文字列を右ペインにそのままコピーできます（ctrl-C/V不要）
6. 「章」や「話」の記号を設定するとミニマップにも表示され便利です。検索ヒットした単語もミニマップに表示されます。
7. `**`や`***`で囲んだ単語は強調表示できます。キーワードをプロットに記載するときなど便利。
8. 「ツール」から、空行を削除したり、会話や見出しの前後に空行を入れたりできます。

![screen shot](スクリーンショット.png)

- 左ペインには参考テキストの他に、右ペインのテキストの初期状態と、初期状態からの差分のタブがあります。
（間違えて消してしまった時などにここからコピーして戻せます）
- ctrl-Zまたは右上の「戻す」でundoできます。
